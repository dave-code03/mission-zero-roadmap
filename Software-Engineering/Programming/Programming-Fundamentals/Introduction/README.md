# 👋 Introduction to Programming

Programming is the process of creating instructions that tell a computer what to do.

Every application, website, game, and AI system is built using programming principles. Before learning any programming language, it is important to understand the core concepts shared by all of them.

---

# 🎯 Mission

Understand what programming is, how computers execute instructions, and why programming is one of the most important skills in Software Engineering.
