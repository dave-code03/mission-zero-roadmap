# 🏗️ Object-Oriented Programming

Object-Oriented Programming (OOP) is a programming paradigm that organizes software around objects and their behavior.

---

## 🎯 Mission

Understand the principles of OOP and learn how to design reusable and maintainable Python code.

---

## 📚 Topics

- Classes
- Objects
- Attributes
- Methods
- Constructors
- `self`
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Composition
- Class Methods
- Static Methods

---

## 🏆 Goal

Design Python programs using object-oriented principles and create reusable software components.
