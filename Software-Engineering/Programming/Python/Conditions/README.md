# 🔀 Python Conditions

Conditions allow programs to make decisions based on whether a statement is true or false.

---

## 🎯 Mission

Learn how to control program behavior by evaluating conditions and making logical decisions.

---

## 📚 Topics

- `if`
- `else`
- `elif`
- Nested Conditions
- Multiple Conditions
- Logical Conditions
- Conditional Expressions
- Truthy and Falsy Values

---

## 🏆 Goal

Build Python programs that can make correct decisions based on different situations.
