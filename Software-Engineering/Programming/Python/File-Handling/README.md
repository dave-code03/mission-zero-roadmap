# 📁 Python File Handling

---

## 📚 Topics

- Opening Files
- Reading Files
- Writing Files
- Appending Data
- File Modes
- Closing Files
- `with` Statements
- Working with Paths
- Text Files
- CSV Files
- JSON Files

---

## 🏆 Goal

Build Python programs that can reliably read, create, update, and manage files.
