# 👥 Users & Permissions

Linux is designed for multiple users, each with specific permissions and responsibilities.

Permissions help protect files and system resources.

---

## 🎯 Mission

Understand user accounts, groups, ownership, and file permissions.

---

## 📚 Topics

- Users
- Groups
- Ownership
- Read, Write & Execute
- chmod
- chown
- sudo
- Root User

---

## 🏆 Goal

Secure Linux systems by managing users and permissions correctly.
