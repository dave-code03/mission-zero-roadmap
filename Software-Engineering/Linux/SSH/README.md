# 🔐 SSH

SSH (Secure Shell) allows secure remote access to Linux systems.

It is one of the most important tools for developers and system administrators.

---

## 🎯 Mission

Learn to connect and manage remote Linux machines securely.

---

## 📚 Topics

- SSH Basics
- SSH Keys
- Password Authentication
- Remote Login
- SCP
- SFTP
- SSH Configuration

---

## 🏆 Goal

Securely access and manage remote servers.
