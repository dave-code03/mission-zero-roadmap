# 📁 File System

The Linux file system organizes files and directories into a hierarchical structure starting from the root directory (/).

Understanding the file system is essential for navigating, managing, and securing a Linux system.

---

## 🎯 Mission

Learn how Linux organizes data and how to navigate the file system efficiently.

---

## 📚 Topics

- Root Directory (/)
- Home Directory
- System Directories
- File Paths
- Absolute vs Relative Paths
- Mount Points
- File Types

---

## 🏆 Goal

Understand the Linux file system and confidently navigate any Linux environment.
