# 📂 Files & Directories

Files store information, while directories organize files into logical groups.

Managing files and directories is one of the most fundamental Linux skills.

---

## 🎯 Mission

Learn to create, organize, move, copy, rename, and delete files and directories safely.

---

## 📚 Topics

- Creating Files
- Creating Directories
- Copying Files
- Moving Files
- Renaming
- Deleting
- Hidden Files
- Symbolic Links

---

## 🏆 Goal

Manage files and directories efficiently using Linux.
