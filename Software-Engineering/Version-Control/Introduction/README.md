# 👋 Introduction to Version Control

Version Control is a system that records changes made to files over time.

It allows developers to track progress, restore previous versions, collaborate with others, and protect their work from being lost.

---

## 🎯 Mission

Understand the purpose of Version Control and why it is an essential skill for every Software Engineer.
