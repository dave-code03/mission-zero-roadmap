# 🔢 Sorting

Sorting algorithms arrange data according to a defined order, making information easier to search, analyze, and process.

---

## 🎯 Mission

Understand common sorting techniques and learn how to compare their performance and use cases.

---

## 📚 Topics

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Sorting Stability
- In-Place Sorting
- Sorting Complexity

---

## 🏆 Goal

Develop the ability to choose, implement, and analyze appropriate sorting algorithms for different problems.
