# 🔁 Recursion

Recursion is a technique in which a function solves a problem by calling itself on smaller instances of the same problem.

---

## 🎯 Mission

Understand recursive thinking and learn how to design, analyze, and safely implement recursive algorithms.

---

## 📚 Topics

- Base Cases
- Recursive Cases
- Recursive Calls
- Call Stack
- Recursive Problem Solving
- Recursion vs Iteration
- Recursive Complexity
- Common Recursive Algorithms

---

## 🏆 Goal

Develop the ability to recognize recursive problems and implement recursive solutions correctly and efficiently.
