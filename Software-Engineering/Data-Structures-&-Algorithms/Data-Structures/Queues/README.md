# 🚶 Queues

A queue is a linear data structure that follows the First In, First Out (FIFO) principle.

Queues are commonly used in scheduling, task processing, buffering, and many software systems.

---

## 🎯 Mission

Understand how queues organize data and learn when they are useful for managing ordered operations.

---

## 📚 Topics

- Queue Structure
- FIFO Principle
- Enqueue
- Dequeue
- Front
- Rear
- Queue Implementation
- Circular Queues
- Queue Applications
- Queue Complexity

---

## 🏆 Goal

Develop the ability to implement and use queues effectively in algorithms and real-world software systems.
